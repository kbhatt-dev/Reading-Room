# My Reading Room V7.0.12 — Hybrid Sync Reliability

## What was fixed

The previous build performed a complete Firestore reconciliation every 60 seconds while the page was visible, and again on focus and visibility changes. Because each reconciliation listed every book and deletion marker, an unchanged open app could consume the daily Firestore read allowance.

V7.0.12 replaces that behavior with low-read hybrid synchronization:

- A local edit automatically pushes only the changed record after a short debounce.
- The changed cloud book/deletion/settings document is checked before writing so a newer remote timestamp is not silently overwritten.
- Full two-way reconciliation runs on signed-in startup, sign-in, bulk restore and **Sync Now**.
- Pending offline edits retry when connectivity returns.
- Edits made while a network request is running retain their newer pending timestamps.

## What did not change

The interface, navigation, shelves, themes, reading sessions, audiobook behavior, statistics, calendar, journals, backups, cover optimization, authentication, Firestore data model and PWA behavior remain unchanged.

## Cross-device use

Changes made on the current device upload automatically. To retrieve them on another device, open/reopen that app or select **Sync Now**.

After deploying this version, close any older open Reading Room tabs or installed PWA windows so the earlier polling build is no longer running.
