# My Reading Room V7.0.11 — Release Notes

**Release date:** August 26, 2026  
**Release type:** Targeted final polish; no redesign or data-model migration.

## Included updates

### Audiobook Reading Details
- Audiobooks use **Total time** and **Current time** rather than Pages and Current page.
- Time controls are separated into **Hr / Min / Sec** and styled to fit the existing Reading Room UI.
- Standard book formats continue using page-based progress.

### Audiobook Reading Sessions
- When the selected Reading book is an audiobook, the session modal changes **Start page / End page** to **Start time / End time**.
- Session lists/history display audiobook progress as time ranges rather than page ranges.
- Non-audiobook session behavior is unchanged.

### Date and time UI
- Added a custom themed calendar/date picker for reading dates.
- The picker uses the existing cream, brown and muted Reading Room palette.
- Hour/minute/second controls were made compact so dropdowns do not dominate the form.

### Mobile Finished shelf
- Finished-page listing shelves now horizontally scroll on phone like the other mobile shelves.
- Books remain reachable instead of being clipped at the edge of the viewport.

### Fairy-light shelf rendering
- Desktop wrapped shelves now create one physical wooden shelf per row.
- Each physical row gets exactly **one continuous leafy fairy-light thread**.
- Removed the visual stacking caused by repeated light strings behind multiple books.
- Light strings remain continuous across the row rather than appearing as cut per-book pieces.

## Preserved behavior

Firebase Authentication/Firestore sync, local/offline storage, PWA behavior, cover compression/fallback, backups/import/export, stats, goals, journals, search, TBR, Reading, Finished data and the established Reading Room design remain unchanged.

## First-open shelf rendering hotfix

- Fixed a TBR/Finished route timing issue where shelf-row geometry could be measured while the page was still hidden.
- The app now re-measures wrapped shelf rows immediately after those pages become active, so the wooden shelf and single fairy-light thread appear on the first visit without refreshing the browser.
- No book data, Firebase sync behavior, or visual design was changed.

#### Mobile Finished shelf containment
- Finished year shelves no longer cause full-page horizontal scrolling on narrow iPhone screens.
- Each year shelf now owns its horizontal swipe area, with the scrollbar hidden for the same clean bookshelf appearance used elsewhere in the app.
