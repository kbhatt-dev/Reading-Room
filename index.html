Data ManagementReset test/library dataOpen

Reset Reading Room Data

Use this when you are finished testing and want a clean library. Your Supabase account, login/profile, and saved connection stay intact.

This permanently clears:

Books and covers, TBR/Reading/Finished/DNF data, reading sessions, journal memories, quotes, predictions, goals/challenges, Hall of Fame/library state, custom genres, and shelf customization.

If you are signed in, the reset also replaces your synced Reading Room cloud payload with the empty library so old dummy books do not download again.

Protected action

Reset Reading Room?

This permanently removes your Reading Room library data from this device and, when signed in, deletes your reading_room_sync cloud row from Supabase. It does not delete your Supabase account/profile or connection.

Recommended: Export a JSON backup first if there is anything you may want later.
